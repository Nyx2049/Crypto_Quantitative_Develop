## 执行摘要

- **光通信正在成为 AI 基础设施的关键瓶颈。** GPU 算力继续增加后，芯片之间、机柜之间和数据中心之间的数据搬运速度、距离与功耗开始决定整套系统效率。
- **当前产业主线是 800G 继续放量、1.6T 开始规模部署、CPO 进入早期产品阶段。** CPO 不会立刻淘汰可插拔光模块，未来几年更可能是铜连接、可插拔模块、LPO 和 CPO 分场景共存。[Marvell][marvell-16t]、[Broadcom][broadcom-th6]和[NVIDIA][nvidia-cpo]已经发布对应产品或平台。
- **中国强在高速光模块规模交付，美国强在交换芯片、DSP 和系统平台，日本强在激光器及精密器件，台湾强在晶圆与先进封装。** LightCounting 的 2025 年模块销售排名为：中际旭创第一、新易盛第二、Coherent 随后、光迅科技第四。[LightCounting][lightcounting-2026]
- **行业景气已经得到财报验证，但股票预期非常拥挤。** 中际旭创、新易盛和 Lumentum 的收入仍在快速增长；与此同时，多只美股光通信公司在 2026 年中出现 15%—40% 级别的月度或季度回撤。产业趋势正确，不代表任何价格都安全。

### 一句话产业链

`材料/晶圆 → 激光器与探测器 → DSP/PIC → 光模块 → 交换机/光网络 → AI 数据中心`

## 一、先把光模块讲明白

> **本节结论：** 光模块不是一颗单独的芯片，而是一套把“电信号—光信号—电信号”连接起来的微型系统。

### 1. 光模块是什么

光模块也叫光收发器（optical transceiver），通常插在服务器、交换机或路由器的端口上：

- **发送端**：把芯片输出的高速电信号变成光信号。
- **传输端**：让光通过光纤完成远距离、低损耗传输。
- **接收端**：把光信号重新转换成电信号。

常见名词：

- **OSFP、QSFP-DD**：模块的外形和接口规范。
- **400G、800G、1.6T**：一个模块可承载的总速率。
- **200G/lane**：单条通道达到 200Gbps，是 1.6T 模块的重要基础。

距离会改变技术路线：

**几米以内**

- 连接方式 → 铜缆、DAC
- 主要场景 → 机柜内连接

**数十米至数百米**

- 连接方式 → VCSEL、EML、硅光直检模块
- 主要场景 → 数据中心机柜间连接

**2—20 公里**

- 连接方式 → coherent-lite、较长距模块
- 主要场景 → 数据中心园区互联

**数十至上千公里**

- 连接方式 → 相干光
- 主要场景 → 城域、骨干网和长距 DCI

更完整的距离分层和 DSP 作用可参考 [Marvell 的官方说明][marvell-dsp]。

### 2. 一只高速光模块由什么组成

**激光器**

- 负责什么 → 产生稳定的光
- 核心壁垒 → 功率、温漂、寿命和批次一致性

**调制器与驱动器**

- 负责什么 → 把 0 和 1 编码到光上
- 核心壁垒 → 高速、低功耗和信号完整性

**复用器与解复用器**

- 负责什么 → 让多种波长共用一根光纤
- 核心壁垒 → 插损、串扰和精密对准

**接收器**

- 负责什么 → 把光重新转换成电
- 核心壁垒 → 灵敏度、噪声和带宽

**DSP/CDR**

- 负责什么 → 修复、均衡和重定时高速信号
- 核心壁垒 → 算法、先进制程、功耗和 SerDes IP

**PIC 光子集成芯片**

- 负责什么 → 在芯片内导光、调制、分光和探测
- 核心壁垒 → 工艺平台、光源集成、耦合和良率

**封装与光纤接口**

- 负责什么 → 把光、电、透镜和光纤装在一起
- 核心壁垒 → 亚微米对准、自动测试、散热和可靠性

Coherent 的材料显示，其能力覆盖激光器、探测器、IC、无源光学件以及 CPO 所需的外置光源和光纤连接单元。[Coherent 年报][coherent-annual] [Coherent OFC 材料][coherent-ofc]

### 3. “光芯片”不是一种芯片

这个词至少包含三类产品：

1. **激光器芯片**  
   真正负责发光，常用砷化镓或磷化铟。EML 适合高速、较长距离；CW 激光常给硅光调制器或 CPO 提供连续光源。

2. **光子集成芯片（PIC）**  
   在芯片内完成导光、分光、调制和探测。硅光适合规模制造和高集成，但硅本身发光效率差，通常仍需要外置或异质集成的 III-V 族激光器。

3. **配套电芯片**  
   DSP、驱动器、TIA 和 SerDes 严格说不是光芯片，却直接决定信号质量、功耗和传输距离。例如 Marvell 的 1.6T Ara 使用 3nm 工艺，把 8 条 200G 电通道与光通道连接起来。[Ara 产品说明][marvell-ara]

### 4. 可插拔模块、LPO 和 CPO 怎么区分

**传统可插拔模块**

- 位置 → 交换机面板
- 优点 → 易更换、生态成熟
- 问题 → ASIC 到面板的高速铜走线越来越耗电

**LPO（线性可插拔光学）**

- 位置 → 交换机面板
- 优点 → 保留可插拔形态，同时减少 DSP 功耗
- 问题 → 链路预算、互操作和系统调试更难

**CPO（共封装光学）**

- 位置 → 靠近交换 ASIC/XPU，甚至放在同一封装内
- 优点 → 缩短电连接，提升密度并降低每比特功耗
- 问题 → 封装、散热、测试和现场维修难度高

**判断：CPO 是方向，但不是一次性替代。** 1.6T 可插拔模块仍在快速放量，CPO 会先进入功耗和端口密度最紧张的高端 AI 交换层。未来更可能是多条路线分层共存。[Broadcom CPO 说明][broadcom-cpo]

## 二、产业链的钱由谁赚

> **本节结论：** 短期利润弹性常出现在已经通过认证并能大规模交付的模块厂；长期技术话语权更集中在 DSP、激光器、交换芯片和先进封装。

### 上游：材料、晶圆和核心器件

**材料与晶圆**

- 代表产品 → InP/GaAs 衬底、硅光晶圆、光纤预制棒
- 代表公司 → AXT、住友电工、TSMC、GlobalFoundries、Corning
- 核心壁垒 → 认证周期长，材料一致性和工艺平台重要

**激光器与探测器**

- 代表产品 → EML、CW 激光、VCSEL、PD/APD
- 代表公司 → Coherent、Lumentum、住友电工、三菱电机
- 核心壁垒 → 高速率、寿命、批次一致性和量产良率

**DSP 与高速模拟芯片**

- 代表产品 → PAM4/相干 DSP、Driver、TIA、SerDes
- 代表公司 → Marvell、Broadcom、Cisco/Acacia、Semtech、MACOM
- 核心壁垒 → 先进制程、算法和系统 IP 高度集中

### 中游：光子集成、模块和制造

**光子集成与 CPO 平台**

- 代表产品 → 硅光 PIC、InP PIC、光引擎和先进封装
- 代表公司 → Broadcom、NVIDIA、TSMC、Marvell、Intel、Coherent
- 核心壁垒 → 技术与资本壁垒很高，但商业化时间仍不确定

**光模块**

- 代表产品 → 400G、800G、1.6T 可插拔模块
- 代表公司 → 中际旭创、新易盛、Coherent、光迅科技、Lumentum
- 核心壁垒 → 客户认证、良率、成本控制和交付规模

**精密制造与测试**

- 代表能力 → 光电组装、耦合、测试和散热
- 代表公司 → Fabrinet、Foxconn、Celestica，以及模块厂自有产线
- 核心壁垒 → 速率越高，自动化、测试能力和良率越重要

### 下游：连接、系统和最终应用

**光纤与连接**

- 代表产品 → 光纤、FAU、高密度连接器和光管理组件
- 代表公司 → Corning、SENKO、住友电工
- 产业位置 → CPO 会增加光纤数量与耦合密度，使其价值提高

**系统与网络**

- 代表产品 → AI 交换机、光传输设备和数据中心互联（DCI）
- 代表公司 → NVIDIA、Broadcom、Cisco、Nokia、Ciena、Arista
- 产业位置 → 掌握系统设计、接口规范和生态话语权

### 利润为什么不会永远留在模块环节

- **景气上行时**：最早通过客户认证、可以交付 800G/1.6T 的模块厂利润弹性最大。
- **技术升级时**：DSP、激光、交换芯片和先进封装更容易形成稀缺能力。
- **成熟降价时**：模块厂要面对客户多供应商策略、年度降价和扩产后的供给竞争。

## 三、龙头、第二梯队与供应关系

> **口径提醒：** 下列“龙头”和“第二梯队”按各自细分产品判断，不能把模块、激光器、DSP 和网络系统混成一个总排名。

### 1. 核心公司地图

**全球光收发模块**

- 龙头 → 中际旭创
- 第二梯队 → 新易盛；其后为 Coherent、光迅科技
- 判断依据 → LightCounting 2025 年光模块销售排名

**美国激光器与光器件**

- 第一梯队 → Coherent、Lumentum
- 第二梯队 → Applied Optoelectronics 等
- 判断依据 → 产品宽度、垂直整合及 AI 客户需求

**光 DSP 与高速连接芯片**

- 第一梯队 → Marvell、Broadcom
- 第二梯队 → Cisco/Acacia 等
- 判断依据 → PAM4、相干 DSP、SerDes 与交换平台能力

**日本化合物光器件**

- 龙头 → 住友电工
- 第二梯队 → 三菱电机
- 判断依据 → 200G EML、CW 激光、PD 和 CPO 器件完整度

**韩国光模块**

- 龙头 → OE Solutions
- 第二梯队 → OptiCore
- 判断依据 → 韩国本土产品与制造能力，不代表全球市场份额排名

**欧洲光网络与相干技术**

- 龙头 → Nokia（已并入 Infinera）
- 第二梯队 → ADTRAN；EFFECT Photonics
- 判断依据 → 系统规模、相干 DSP/PIC 和产品完整度

**CPO 系统平台**

- 第一梯队 → Broadcom、NVIDIA
- 第二梯队 → Marvell、Intel 等
- 判断依据 → 产品化进度、交换/XPU 平台及封装生态

模块排名依据为 [LightCounting][lightcounting-2026]，只统计光收发模块销售，不代表整个光子产业。

### 2. 已经公开确认的合作关系

- **NVIDIA CPO 生态**：公开列出 TSMC、Coherent、Corning、Foxconn、Lumentum 和 SENKO。[NVIDIA][nvidia-cpo]
- **Broadcom CPO**：Tomahawk 6 Davisson 使用 TSMC COUPE 光子平台。[Broadcom][broadcom-th6]
- **Coherent 1.6T 模块**：公开使用 Marvell Ara DSP。[Coherent][coherent-home]
- **Nokia 与 Infinera**：Nokia 已完成收购，获得 Infinera 的光网络系统、相干 DSP 与 PIC 能力。[Nokia][nokia-infinera]

### 3. 供应关系最容易犯的四个错误

1. **客户认证不等于独家供货。** 超大规模云厂商通常会同时认证多家模块厂。
2. **合作演示不等于量产订单。** 展会样机只能证明兼容或联合开发。
3. **进入 NVIDIA 生态不等于供应所有 GPU 平台。** 官方名单不能直接反推出各公司收入占比。
4. **社交媒体的精确供货比例不能替代法定披露。** 中际旭创、新易盛的具体核心客户和供应商多数未公开确认。

## 四、全球各地区分别强在哪里

### 全球分工速览

**中国**

- 最强环节 → 高速光模块规模制造
- 代表公司 → 中际旭创、新易盛、光迅科技

**美国**

- 最强环节 → 交换芯片、DSP、系统平台和高端激光器
- 代表公司 → NVIDIA、Broadcom、Marvell、Coherent、Lumentum

**日本**

- 最强环节 → 化合物半导体、激光器、探测器和精密器件
- 代表公司 → 住友电工、三菱电机

**中国台湾**

- 最强环节 → 光子晶圆、先进封装和规模制造
- 代表公司 → TSMC、Foxconn

**韩国**

- 最强环节 → 本土电信模块与追赶型供应链
- 代表公司 → OE Solutions、OptiCore

**欧洲**

- 最强环节 → 相干光网络、运营商系统与 InP 生态
- 代表公司 → Nokia、ADTRAN、EFFECT Photonics

### 中国：模块规模和客户认证领先

中际旭创和新易盛依靠海外云客户认证、800G/1.6T 迭代与制造规模进入全球第一梯队。中际旭创 2025 年收入 382.4 亿元，同比增长 60.3%；新易盛 2025 年收入 248.4 亿元，明显高于 2024 年的 86.5 亿元。[中际旭创 2025 年报告][innolight-2025] [新易盛 2025 年披露][eoptolink-2025]

主要短板仍是高端 DSP、部分高速激光芯片、先进光电测试设备和海外政策风险。2026 年 8 月有媒体转述 Reuters 称美国正讨论限制新型号中国光收发器进口，但截至本报告时间未检索到 FCC 正式规则。应把它视为**高影响、未落地风险**，而不是既成禁令。[媒体报道][policy-report]

### 美国：定义平台和接口

美国的优势不只是生产光模块，而是决定整套系统如何连接：

- Broadcom、NVIDIA 定义 CPO 与 AI 交换平台。
- Marvell、Cisco/Acacia 掌握高速 DSP 与相干技术。
- Coherent、Lumentum 覆盖激光、器件和模块。
- Corning 提供光纤与高密度连接方案。

### 日本：关键器件积累深

日本没有占据全球高速模块品牌前列，但在 InP/GaAs 化合物半导体、EML、CW 激光、探测器、PLC 和精密制造上积累深厚。三菱电机已经量产 200Gbps EML；住友电工提供 EML、CPO 外置光源和光纤到 PIC 的耦合器件。[三菱电机][mitsubishi] [住友电工][sumitomo-flex]

### 中国台湾：晶圆与先进封装是核心位置

TSMC 的 COUPE 平台把电芯片堆叠在光子芯片上，Broadcom 已公开采用；Foxconn 进入 NVIDIA CPO 生态。护城河主要来自光电协同制造、先进封装和规模化，而非单一光模块品牌。[TSMC][tsmc-coupe]

### 韩国：本土供应链仍在追赶

OE Solutions 覆盖无线和有线光收发器，OptiCore 拥有 400G 产品，但在 800G/1.6T 规模和全球云客户方面仍落后于中美头部厂商。OptiCore 2026 年还披露审计意见导致交易停止，说明小型公司的技术叙事与财务质量需要分开判断。[OE Solutions][oe-solutions] [OptiCore][opticore]

### 欧洲：强在相干光网络和运营商系统

Nokia 收购 Infinera 后强化了光网络系统、DSP 和 PIC 能力；ADTRAN 在 2026 年推出 800G LPO；荷兰 EFFECT Photonics 聚焦可调谐激光和相干光，但规模不能与全球头部公司直接比较。[Nokia][nokia-ai] [ADTRAN][adtran-lpo] [EFFECT Photonics][effect-photonics]

## 五、关键人物与 X 观点

> **使用原则：** 公开人物和 X 账号适合发现线索，但不能替代公司公告、财报和量产数据。

### 黄仁勋 / NVIDIA

- **公开观点**：当 AI 工厂扩大到百万 GPU 规模后，需要把硅光更直接地集成进交换系统，以改善功耗、密度和可靠性。
- **对应产品**：Spectrum-X、Quantum-X Photonics。
- **验证情况**：NVIDIA、Broadcom 和 Marvell 的后续产品说明 CPO 已进入产品阶段，但大规模部署速度仍待验证。[NVIDIA 官方发布][nvidia-cpo]

## 七、真正的护城河与常见误区

### 较强的护城河

1. **高速激光器和光电芯片量产**  
   200G/lane EML、CW 激光和窄线宽激光不仅要性能达标，还要寿命、温漂与批次一致性达标。

2. **DSP、SerDes 与交换芯片 IP**  
   先进制程、算法、模拟前端和系统知识集中在少数公司。

3. **光电封装、耦合和测试良率**  
   CPO 和 1.6T 把问题从“芯片能不能工作”升级为“整套系统能不能低成本量产和现场维护”。

4. **超大客户认证与持续交付能力**  
   云厂商验证周期长，进入供应链后仍需持续降本、扩产并维持可靠性。

5. **垂直整合能力**  
   Coherent 一类公司能在激光、探测、无源光学和模块之间调整自研与外采，供应受限时更灵活；代价是资本开支更重。

### 最容易被高估的故事

- 把展会样机、送样或合作备忘录直接当成量产订单。
- 任何光学、激光或精密加工公司都被贴上 CPO 标签。
- 把“列入合作生态”解读为独家供应商。
- 只看市场空间，不看单位价格下降、客户多供策略和扩产良率。
- 用 CPO 的长期替代逻辑，否定未来两三年 800G/1.6T 可插拔模块需求。

## 八、未来 3—5 年的驱动与风险

### 五个核心驱动

1. **AI 集群继续扩展**：GPU 增多会同步放大机柜内、机柜间和数据中心间流量。
2. **800G 向 1.6T 迁移**：Marvell 已表示 1.6T Ara 量产，Coherent、Lumentum、Cisco 等都有产品或验证。
3. **每比特功耗成为硬约束**：交换容量走向 102.4Tbps 及以上后，CPO、LPO 和新型 DSP 的经济性提高。
4. **数据中心跨园区和跨区域互联**：400ZR/800ZR、coherent-lite 和长距相干继续增长。
5. **供应链本土化**：美国扩张激光和光纤产能，中国推动高端光芯片国产化，日本与欧洲强化器件和相干能力。

### 六个主要风险

1. **CPO 量产延迟**  
   观察 → 光纤耦合、外置激光、热管理、测试和现场维护成本。

2. **客户过度集中**  
   观察 → 单个云客户切换产品代际或供应商时，对收入的影响。

3. **价格下降与扩产过度**  
   观察 → 单位售价下降是否快于出货量增长。

4. **技术路线切换**  
   观察 → EML、硅光、LPO、CPO 和光 I/O 的实际采用节奏。

5. **地缘政策**  
   观察 → 正式法规文本，而不是媒体传闻或市场猜测。

6. **估值脱离基本面**  
   观察 → 未来订单增长能否兑现当前盈利预期。

## 九、研究时应该持续跟踪什么

### 公司与产业跟踪清单

- [ ] 中际旭创、新易盛的 1.6T 收入占比、出货量和毛利率。
- [ ] Coherent、Lumentum 的 200G EML/CW 激光扩产、良率和长期合同。
- [ ] NVIDIA 与 Broadcom CPO 产品的真实客户、端口数量、故障率和维护成本。
- [ ] Marvell、Broadcom、Cisco/Acacia 在 1.6T PAM4 和相干 DSP 中的份额。
- [ ] 光纤连接、FAU、外置光源和测试设备是否成为新产能瓶颈。
- [ ] 美国是否发布针对中国光收发器的正式规则。
- [ ] 高速模块单位售价下降是否快于出货增长。
- [ ] 云客户是否把订单从两家供应商扩大到三家或更多。

### 看一家“光概念公司”时先问三个问题

1. **产品是否已经量产，而不只是送样或展示？**
2. **客户是否完成真实认证，关系是否来自公司披露？**
3. **收入、毛利率和现金流是否已经体现这项业务？**

## 十、最终判断

光通信正在从传统电信周期行业，转变为 AI 基础设施中的核心“数据搬运层”。短期业绩弹性最明显的是高端光模块和激光器；长期技术话语权更可能掌握在 DSP、交换芯片、光源、硅光平台、先进封装和系统生态手中。

用于选股时，首先要确认公司究竟处在产业链哪一层，然后把**量产、认证和财务兑现**放在概念之前。只有 CPO 叙事、没有客户和规模收入的小公司，应按高技术风险和高融资风险看待；已经大涨的龙头，也需要把未来订单增长和当前估值分开判断。

> **固定提示：本报告用于产业研究，不构成投资建议。**
