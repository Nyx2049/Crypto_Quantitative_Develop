# 二代低介电电子布：AI 高速 PCB 的隐形材料升级

> **调研对象**：市场俗称“二代布”的第二代低介电电子玻纤布，重点研究 PCB/覆铜板应用  
> **研究边界**：玻璃配方、电子纱、电子布、覆铜板、PCB 与 AI 服务器/交换机；不延伸到普通建筑玻纤  
> **信息截止**：2026 年 8 月 14 日；公司进展以已公开材料为准  
> **行情口径**：采用 2026 年 7 月下旬可取得的第三方行情快照，仅用于观察交易拥挤度  
> **生成时间**：2026 年 8 月 14 日（北京时间 UTC+8）

## 执行摘要

- **“二代布”是产业俗称，不是全球统一标准。** 日东纺把 NER-glass 明确称为第二代低介电玻璃，但国内厂商的 Low-Dk 一代、二代命名并不保证与 NER 完全等价。判断产品代际应看测试频率、介电常数 Dk、介质损耗 Df、布种、认证客户和批量销售，而不是只看名称。
- **需求来自高速信号传输，而不是“AI”三个字本身。** GPU 集群把交换速率推向 800 GbE、1.6 TbE，服务器主板、交换机和网卡的 PCB 需要降低传输损耗和时延。玻纤布虽然价值量不如芯片显眼，却会影响覆铜板的介电性能、尺寸稳定性和高速信号一致性。
- **真正壁垒是五项能力的组合。** 特种玻璃配方、超细电子纱稳定拉丝、低缺陷织造、开纤/表面处理和下游长期认证缺一不可。购买日本喷气织机只能解决部分设备问题，不能直接复制合格产品。
- **日本仍是技术标杆，中国进入规模验证阶段。** 日东纺拥有 NE → NER → NEZ → DXII 的连续路线；旭化成正推进下一代布和石英布。中国的中材科技、国际复材、宏和科技已经分别披露低介电产品认证、批量供应或收入，但各自披露口径不同，不能把全部电子布产能都算成二代布。
- **这是一条供需紧、但透明度低的赛道。** 龙头企业披露了扩产、满负荷或高性能布销售增长，能够支持“景气上行”的判断；市场流传的全球需求量、缺口比例以及某款 NVIDIA 产品指定供应商，尚缺统一的官方 BOM 或可交叉验证数据。
- **股票已经交易了很强的预期。** 多只 A 股、日股和台股相关标的曾在一年内大幅上涨，随后出现明显月度回撤。产业趋势成立不等于股价赔率始终合适，需把产品认证、实际销量和利润兑现与主题情绪分开观察。

## 一、先弄懂二代布

> **本节结论：** 二代布是覆铜板中的增强骨架兼电气材料。它解决的是高速信号经过 PCB 时损耗过大、延迟不一致的问题，但它不能单独决定整块 PCB 的性能。

### 1. 一张高速 PCB 是怎么叠出来的

最简化的结构是：

**特种玻璃原料 → 电子级玻璃纤维纱 → 电子玻纤布 → 浸渍树脂形成半固化片 → 与铜箔压合成覆铜板 → 制成 PCB → 装入服务器/交换机。**

- **电子纱** → 由熔融玻璃经过铂金漏板高速拉成极细纤维，再集束、上浆或捻制。
- **电子布** → 把电子纱按指定经纬密度织成极薄、均匀的布，是覆铜板的增强骨架。
- **半固化片（Prepreg）** → 电子布浸入树脂后形成的可层压材料。
- **覆铜板（CCL）** → 半固化片与铜箔压合后的 PCB 基材。
- **印制电路板（PCB）** → 在覆铜板上加工线路、孔和焊盘，承载高速信号与电子器件。

玻纤布约束树脂、提供机械强度和尺寸稳定性，同时自身也处于电磁场中。因此，布的介电性能、厚度、均匀度和玻璃纱分布都会影响高速线路。

### 2. Dk、Df 到底是什么

**介电常数（Dk）**

- 通俗理解 → 信号经过材料时“被拖慢”的程度。
- 产业意义 → Dk 越低，通常越有利于降低传播延迟并控制阻抗；但最终性能取决于玻纤、树脂、铜箔和结构的共同组合。

**介质损耗因子（Df）**

- 通俗理解 → 高频信号的能量有多少在材料中变成热并消失。
- 产业意义 → Df 越低，长距离、高频率线路的插入损耗越小。高速交换机和 AI 服务器往往比普通消费电子更在意 Df。

**频率口径很重要。** 同一种材料在 1 GHz、10 GHz 和更高频率下的数据不能直接横向拼接。日东纺公开的玻璃块实测示例显示：普通 E-glass 在 10 GHz 下 Dk 约 6.6、Df 约 0.0060，NE 约 4.7/0.0025，NER 约 4.5/0.0018；这些是公司实测示例，不是所有布种的保证规格。[日东纺 2025 综合报告](https://www.nittobo.co.jp/eng/ir/pdf/Nittobo_Integrated-Report_2025.pdf)

### 3. “一代、二代、三代”为什么容易说乱

国内市场常把低介电玻纤布分代讨论，但这不是像 USB 版本那样的统一标准。比较稳妥的理解如下。

**普通 E-glass**

- 主要特点 → 成本低、机械和绝缘性能成熟。
- 适用范围 → 普通 PCB、对高速损耗不敏感的场景。
- 限制 → Dk、Df 较高，高频长链路损耗更明显。

**第一代低介电布 · 常对应 NE 类路线**

- 主要特点 → 通过改变玻璃成分，降低 Dk 和 Df。
- 典型应用 → 100G/400G 通信、高速服务器板等。
- 注意 → “一代”不是 IPC 的正式代际名称。

**第二代低介电布 · 常对应 NER 或同级 Low-Dk/Df 路线**

- 主要特点 → 在第一代基础上进一步降低高频损耗。
- 典型应用 → 800G 交换、AI 服务器主板和高速网卡等。
- 判断方法 → 不能只看厂商宣传，要核对 Df、测试频率、布种、量产状态和客户认证。

**更先进低损耗路线 · NEZ、超低损耗 Low-Dk 等**

- 主要特点 → 为 1.6T 及后续平台继续降低损耗。
- 状态 → 多家公司仍处于扩产、认证或导入阶段；日东纺已公开 NEZ 和 DXII 路线图。

**低热膨胀布（Low-CTE/T-glass）**

- 解决问题 → 降低芯片封装基板受热时的尺寸变化和翘曲。
- 与二代布关系 → 一个重点解决热机械稳定，一个重点解决介电损耗；可以同时需要，但不能视为同一种产品。

**石英布（Q-cloth）**

- 主要特点 → 石英材料具有更低介电损耗潜力。
- 限制 → 成本、纤维制造、织造和大规模认证难度更高。
- 产业判断 → 更可能先进入极高端场景，与高性能 Low-Dk 布并存，而不是立即替代全部二代布。

2024 年发布的 [IPC-4413](https://www.electronics.org/recently-released-ipc-standards-and-documents) 已专门规范用于印制板的低 Dk 玻璃纤维成品布。这说明低介电布已进入标准化阶段，但该标准仍没有替市场定义一个通用的“一代/二代”命名。

### 4. 不能只看 Dk/Df

一块高速覆铜板的损耗还取决于：

- 树脂体系的 Dk/Df 与吸水率；
- 铜箔表面粗糙度带来的导体损耗；
- 玻纤经纬分布造成的玻纤编织效应（Glass Weave Effect）；
- 布的开纤、扁平度、厚度和缺陷；
- CTE、耐热性、剥离强度、CAF 可靠性；
- PCB 线宽、层叠、过孔和信号走线路径。

因此，“某种布 Df 更低”不等于整块 CCL 或 PCB 的系统性能必然更好，最终必须通过下游配方、制板和整机验证。

## 二、它为什么被 AI 服务器需要

> **本节结论：** 算力芯片越多，芯片之间搬运数据的速度越重要。二代布受益于网络与板级传输升级，而不是单纯受益于 GPU 数量。

### 1. 从 400G 到 800G、1.6T

AI 集群内部既有服务器主板上的高速通道，也有网卡、交换机和背板之间的长距离高速连接。速率提高后，单位时间内的电信号边沿更快，对材料损耗和阻抗一致性更敏感。

日东纺公开的应用路线把 NE 与 400 GbE、NER 与 800 GbE 对应，并把 NE/NER/NEZ 放入 AI 服务器、核心交换机和服务器主板的候选材料中。这是厂商自己的产品路线图，不代表所有系统都采用同一配置，但能说明材料升级方向。[日东纺 2025 综合报告](https://www.nittobo.co.jp/eng/ir/pdf/Nittobo_Integrated-Report_2025.pdf)

### 2. 哪些设备更可能用

- **AI 服务器主板** → CPU、GPU、内存、网卡之间存在 PCIe、DDR 和高速 SerDes 链路。
- **数据中心交换机** → 端口速率和交换容量高，PCB 层数多、走线长，对插入损耗更敏感。
- **高速网卡与加速卡** → 芯片与光模块/连接器之间需要保持信号完整性。
- **路由器与通信基站** → 高频高速传输同样需要低损耗材料，但需求节奏不完全等同于 AI 服务器。

### 3. 用量不能靠“GPU 数量 × 一个固定系数”推算

公开资料通常不会披露每台服务器、每块交换机使用多少米特定代际电子布。用量受 PCB 面积、层数、布种、良率、替代配方和 CCL 厂裁切效率影响。

目前未找到 NVIDIA 官方 BOM 能确认某一代平台必然使用哪家二代布、单机用量或独家份额。市场调研中常见的“指定供应商”“全球缺口百分比”应视为待验证线索，不能替代厂商订单和客户认证。

### 4. 整板性能比单一材料标签更重要

下游 CCL 已经进入更低损耗平台。例如 [Panasonic MEGTRON 8](https://industrial.panasonic.com/sa/products/pt/megtron/megtron8) 提供面向 AI 服务器和网络设备的低损耗材料，并可选低 Dk/超低 Df 玻纤；[Doosan DS-9000](https://www.doosanelectronics.com/en/product/Copper_Clad_Laminate/DS-9000) 面向服务器和 6G 等场景。两者公布的是整个层压板性能，不应倒推为某家玻纤布的单独参数。

## 三、怎么制造，壁垒在哪里

> **本节结论：** 配方决定理论上限，制造一致性和认证决定能不能赚钱。最难的是持续生产“每一米都一样”的超细低损耗布。

### 1. 制造流程

1. **玻璃配方与配料** → 调整 SiO₂、B₂O₃ 和碱土金属氧化物等成分，兼顾低介电、可熔制和机械强度。
2. **高温熔融** → 原料在约 1,600°C 的窑炉中形成均匀玻璃液。
3. **铂金漏板拉丝** → 玻璃液通过铂铑合金漏嘴高速拉成微米级纤维；漏板精度、温度和玻璃液稳定性影响纱线一致性。
4. **集束与上浆** → 施加浸润剂，减少毛羽和断丝，并为后续树脂结合做准备。
5. **整经与喷气织造** → 严格控制经纬密度、张力、厚度和缺陷。
6. **退浆/热清洗** → 去除织造所需浆料，避免残留影响电气与粘结性能。
7. **开纤与扁平化** → 让纱束铺展，减小玻纤编织效应并改善树脂浸润。
8. **硅烷处理与检验** → 提高与树脂的界面结合，再检测外观、厚度、强度、电气和可靠性。

[日本玻璃纤维协会的制造说明](https://www.glass-fiber.net/glasswool_long_process.html)显示，连续玻纤需要在高温下通过铂金漏嘴高速拉丝。丰田自动织机的 [JAT810 喷气织机](https://www.toyota-industries.com/products/textile/shokki/index.html)代表高端织造设备，但产品良率仍取决于企业自己的纱线、工艺参数和后处理。

### 2. 五层核心壁垒

**玻璃配方**

- 难点 → 降低 Dk/Df 往往会改变黏度、熔融窗口、强度和拉丝稳定性。
- 护城河 → 长期配方数据库、窑炉工艺和知识产权。

**超细电子纱**

- 难点 → 纤维越细，断丝、毛羽、直径波动和漏板寿命越难控制。
- 护城河 → 玻璃液均匀度、漏板技术、浸润剂和在线控制。

**织造与后处理**

- 难点 → 经、纬张力以及开纤不均会造成局部 Dk 差异和信号偏斜。
- 护城河 → 设备改造、工艺参数、缺陷识别和稳定良率，而不仅是织机品牌。

**客户联合开发与认证**

- 难点 → CCL 厂要重新匹配树脂、压合和可靠性参数，终端还需验证信号完整性。
- 护城河 → 认证周期、批次稳定性、长期交付记录和失效成本。

**规模与成本**

- 难点 → 特种纱/布初期销量小，频繁换规格会降低产线效率。
- 护城河 → 一体化纱布产能、规模摊销、产品组合和稳定订单。

### 3. 为什么“有产能”不等于“有二代布产能”

电子布产线可以生产普通厚布、薄布、超薄布和高性能布。企业公告中的“电子布总产能”通常不能直接视作 Low-Dk 二代布产能；还要核对：

- 专用玻璃配方是否已形成稳定电子纱；
- 高性能布占总产量和收入多少；
- 处于送样、认证、小批量还是稳定批量；
- 客户是否为高端 CCL 头部厂商；
- 是自制电子纱还是外购特种纱织布；
- 披露的是一代、二代、低 CTE 还是石英布。

## 四、产业链与价值分配

> **本节结论：** 价值更集中在特种玻璃配方、电子纱/布稳定制造和高端 CCL 配方认证，普通矿物原料与通用织造的稀缺性较低。

### 上游：原料、耗材与装备

**特种玻璃原料**

- 主要产品 → 高纯石英砂、硼化合物、氧化铝、碱土金属原料等。
- 价值来源 → 纯度与批次稳定性。
- 竞争判断 → 原料重要，但最终配方和熔制能力通常掌握在纱厂手中。

**铂铑漏板与窑炉**

- 主要作用 → 把均匀玻璃液稳定拉成极细纤维。
- 价值来源 → 高温材料、微孔加工、寿命和温控。
- 供应关系 → 重点厂商通常不完整披露具体漏板供应商，不宜硬配公司名单。

**浸润剂与硅烷偶联剂**

- 主要作用 → 减少毛羽断丝，改善纤维与树脂界面。
- 价值来源 → 配方需要与玻璃和下游树脂共同匹配。

**喷气织机与整经设备**

- 主要代表 → 丰田自动织机、津田驹。
- 主要作用 → 高速、精密织造超薄电子布。
- 关键提醒 → 设备是必要条件之一，不是二代布的充分条件。

### 中游：电子纱与电子布

**特种电子纱**

- 主要公司 → 日东纺、台玻、中材科技、国际复材、中国巨石等。
- 价值来源 → 配方、拉丝良率、细纱一致性。

**低介电电子布**

- 主要公司 → 日东纺、旭化成、台玻、中材科技、国际复材、宏和科技等。
- 价值来源 → 纱布协同、开纤/表面处理、客户认证和稳定批量交付。
- 商业模式 → 按布种和性能销售，极薄与特种布溢价通常高于普通电子布。

### 下游：CCL、PCB 与系统设备

**高频高速覆铜板**

- 主要公司 → 松下电工电子材料、斗山电子、台光电子、台燿、联茂、南亚新材、生益科技等。
- 价值来源 → 树脂配方、铜箔/玻纤匹配、层压工艺、认证平台。

**高多层 PCB**

- 主要公司 → 供应链随终端平台变化，需按具体客户项目验证。
- 价值来源 → 层数、背钻/过孔、良率和高速信号设计能力。

**终端系统**

- 主要应用 → AI 服务器、交换机、网卡、路由器、基站和高性能计算设备。
- 采购特点 → 终端常通过 CCL/PCB 认证链条间接决定材料，不一定直接向玻纤布厂采购。

## 五、全球公司格局

> **本节结论：** 日本在材料代际与高端产品上领先，台湾拥有纱布—CCL—PCB 的密集生态，中国大陆正在完成国产认证和规模爬坡，韩国强项更偏高端 CCL。美国和欧洲是标准、设备或终端需求的重要参与者，但没有必要强行选出本土“二代布第一名”。

- 行业位置 → 特种玻璃技术标杆；公司明确将 NER 称为第二代低介电玻璃。

- 主要应用 → AI 服务器、交换机、路由器、内存和半导体封装基板。
- 竞争优势 → 自主玻璃配方、电子纱和玻纤布协同、长期客户验证、连续产品路线。
- 公开进展 → 公司称 AI 等需求明显高于原规划，正扩充玻纤布体系；同时承认中国和台湾厂商在追赶。[日东纺综合报告](https://www.nittobo.co.jp/eng/ir/pdf/Nittobo_Integrated-Report_2025.pdf)
- 主要供应商 → 未可靠披露；不能因为设备产自日本就推定具体采购关系。
- 排名依据 → 技术代际、公司官方命名和高端应用路线；不是依据未经核实的全球份额数字。

- 行业位置 → 超薄电子布和高附加值玻纤布的重要日本厂商。

- 公开进展 → FY2025 玻纤布销售同比约增 10%；公司预计 FY2026 再增 10%～20%。下一代布计划在 FY2026 加速销售，石英布目标 FY2026 完成客户资格、FY2027 开始形成完整销售贡献。[旭化成 FY2025 业绩问答](https://www.asahi-kasei.com/content/dam/asahi-kasei/us/en/ir/library/financial-briefing/pdf/260512summary.pdf)

## 六、重点公司进度

> **本节结论：** 观察公司时要把“研发—送样—认证—小批量—稳定批量—收入占比”放在一条进度线上，不能只看公司是否说过“二代”。

### 已形成明确技术标杆

**日东纺**

- 当前阶段 → NER 已量产，NEZ/DXII 继续迭代。
- 证据强度 → 高；公司官方产品参数、路线图和产能计划相互印证。
- 最关键变量 → 扩产速度、客户从 NE 向 NER/NEZ 切换速度、定价能力。

### 已披露认证与批量供货

**中材科技**

- 当前阶段 → 多类高性能布获认证并批量供应。
- 证据强度 → 中高；年报披露明确，但缺少细分销量、单价和客户名单。
- 最关键变量 → 二代与超低损耗布的真实收入占比和利润率。

**宏和科技**

- 当前阶段 → 高性能布稳定销售，低介电布销量有量化披露。
- 证据强度 → 中高；销量和收入清楚，但“低介电”未全部拆分到第二代。
- 最关键变量 → 自制高性能电子纱爬坡、二代布占比、客户扩散与毛利兑现。

**台玻**

- 当前阶段 → 一、二代 Low-Dk 与 Low-CTE 已认证并采用。
- 证据强度 → 中；公司官方确认，但缺少各代产品的销量和收入拆分。
- 最关键变量 → 高端布产能、客户平台与综合玻璃业务对利润的稀释。

### 正在推进下一代或多路线导入

**旭化成**

- 当前阶段 → 下一代布 FY2026 加速销售；石英布认证中；低 CTE 布处于客户评价阶段。
- 证据强度 → 高；管理层业绩问答明确区分各阶段。
- 最关键变量 → 下一代布收入增长、特种纱供应、石英布资格进度。

**国际复材**

- 当前阶段 → 已展示二代 Low-Dk 等完整产品矩阵，量产和收入纯度仍需继续跟踪。
- 证据强度 → 中；产品存在明确，批量客户和收入证据相对不足。
- 最关键变量 → 客户认证、量产良率与电子业务收入贡献。

**中国巨石**

- 当前阶段 → 扩充电子纱/布能力，但公开新产能不能直接标记为二代 Low-Dk。
- 证据强度 → 中低；规模规划明确，产品代际口径不足。
- 最关键变量 → 特种玻璃配方、二代布认证和专项收入披露。

### 一个实用的证据分级

- **A级** → 年报或官方资料披露客户认证、批量销售，并给出销量/收入。
- **B级** → 官方披露已认证或批量，但没有细分经营数据。
- **C级** → 官方披露送样、客户评价、研发或展会产品。
- **D级** → 券商/媒体/社交账号转述，找不到公司或客户原始材料。

研究二代布时，最应该盯 A、B 级证据的变化，而不是 D 级传闻的数量。

## 九、未来驱动、风险与跟踪清单

> **本节结论：** 未来 3～5 年的主线是更高速网络推动材料升级，中国供应商争取国产认证；最大风险则是预期跑得比量产快，以及下一代材料改变竞争顺序。

### 主要驱动

1. **800G/1.6T 网络扩张** → 交换机、网卡和高速主板对低损耗材料的需求提升。
2. **AI 服务器 PCB 层数和高速通道增加** → 单块板的高性能 CCL 使用面积和技术要求可能提升。
3. **国产供应链认证** → 中国 CCL/PCB 厂希望降低单一海外材料依赖，为本土纱布厂提供验证窗口。
4. **产品结构升级** → 普通电子布厂若成功切入 Low-Dk、Low-CTE 和超薄布，单位盈利可能改善。
5. **技术继续迭代** → NEZ、超低损耗 Low-Dk、石英布等推动高端材料价值量继续上移。

### 主要风险

**代际口径混乱**

- 风险 → 公司只说“高性能”“低介电”，市场便全部计入二代布。
- 验证 → 要求测试指标、频率、布种、客户认证和细分收入。

**扩产快于需求**

- 风险 → 高价和短缺吸引大量产能，客户完成认证后议价、降价。
- 验证 → 观察产能利用率、库存、价格和交付周期，而不是只看规划产能。

**良率爬坡不及预期**

- 风险 → 实验室样品合格，但连续拉丝、织造和后处理的批次稳定性不足。
- 验证 → 批量销量、退货/质量损失、毛利率和客户复购。

**下一代材料替代**

- 风险 → NEZ、石英布或新的树脂/线路设计降低现有二代布的生命周期和溢价。
- 验证 → 下游 CCL 新平台选材以及日东纺、旭化成的认证节奏。

**客户和供应链不透明**

- 风险 → 市场把“进入某 CCL 厂供应链”误写成“用于某终端旗舰平台”。
- 验证 → 客户双方披露、终端认证、订单和收入同时出现。

**估值与交易拥挤**

- 风险 → 相关股票一年涨幅巨大，即使业绩增长也可能低于市场隐含预期。
- 验证 → 用细分利润增量对比市值增量，避免只比较收入增速。

### 每季度值得检查的事项

- [ ] 日东纺 NER/NEZ 扩产是否按计划投产，是否继续提价或改善产品结构。
- [ ] 旭化成下一代玻纤布 FY2026 销售是否真正加速，石英布是否按期获认证。
- [ ] 中材科技是否披露二代/超低损耗布的销量、收入或核心客户进展。
- [ ] 宏和科技低介电布销量和高性能收入占比是否继续增长，毛利是否同步改善。
- [ ] 国际复材是否从展品/送样推进到明确客户认证和批量收入。
- [ ] 台玻是否披露一代、二代 Low-Dk 的产能利用率或具体收入。
- [ ] 高端 CCL 厂是否上调或下调对 Low-Dk、Low-CTE、石英布的采购计划。
- [ ] 电子布报价上涨是否来自二代布真实短缺，还是普通布周期性涨价。
- [ ] 是否出现客户双供、国产替代或新一代材料切换导致的份额变化。
- [ ] 上市公司市值上涨是否明显快于可验证的二代布利润增量。

## 结论

二代低介电电子布的核心价值，是在高速 PCB 中减少介质损耗并提高信号一致性。它属于“整机中占比不显眼、但性能失配会拖累整个系统”的关键材料。

产业上，日东纺仍是最清晰的技术标尺；旭化成在下一代和石英路线积极推进；台玻拥有纱布一体化和台湾电子产业生态；中材科技、宏和科技、国际复材等中国厂商已经进入从认证到批量兑现的不同阶段。真正值得持续跟踪的不是谁在公告里出现“二代”两个字，而是谁能稳定交付、进入多个客户平台，并把销量转化为可持续毛利。

资本市场上，相关公司已经经历强烈的主题交易。后续最重要的分水岭将是细分收入、良率、客户复购和新代际认证，而不是更多未经验证的供应链传闻。
