# mSAP：把 PCB 线路从“刻出来”变成“长出来”

> **调研对象**：改良型半加成法（Modified Semi-Additive Process，mSAP）及其直接产业链  
> **研究边界**：极薄铜箔、干膜、曝光、电镀、闪蚀、检测设备，以及 HDI、类载板和封装基板制造；不把全部 PCB 和先进封装收入都算入 mSAP  
> **信息截止**：2026 年 8 月 14 日；量产与客户进度以公司公开资料为准  
> **行情口径**：采用 2026 年 7 月下旬附近可取得的第三方行情快照，只用于观察预期和交易拥挤度  
> **生成时间**：2026 年 8 月 14 日（北京时间 UTC+8）

## 执行摘要

- **mSAP 是工艺，不是材料，也不是一个独立终端市场。** 它从极薄底铜出发，只在需要线路的位置电镀“长铜”，再快速去掉裸露底铜，能够减轻传统减成法的侧蚀，使线路更窄、更接近矩形。受益环节必须拆成 PCB 厂、极薄铜箔、干膜、直接成像、电镀化学品/设备和检测设备分别研究。
- **它是 HDI 向类载板升级的现实桥梁。** mSAP 沿用部分传统 CCL 和 HDI 产线知识，量产成本通常低于完全从绝缘层起步的 SAP；因此适合约 15～40 μm 级精细线路。更细的 IC 封装基板通常转向 SAP，两者不是简单的先进与落后关系。
- **真正瓶颈是整线良率，而不是拥有某一台设备。** 极薄铜箔剥离、干膜附着与解析、LDI 对位、电镀均匀性、微孔填孔、闪蚀窗口和 AOI 缺陷反馈必须同时稳定。公司公告中的“具备 mSAP 技术”与“20/20 μm 产品大批量出货”之间差别很大。
- **产业标杆分散在不同环节。** 臻鼎是具备 mSAP 量产能力的全球 PCB 龙头；AT&S 明确在上海和重庆生产高端 mSAP PCB；三井金属称其 MicroThin 载体极薄铜箔全球份额超过 95%；MKS/Atotech、SCREEN、KLA 等掌握电镀、湿制程、直接成像和检测方案。中国的崇达技术子公司已披露 20/20 μm mSAP 产品大批量出货，芯碁微装披露 6/6 μm LDI 设备已在封装载板头部客户验收量产。
- **AI 是新增驱动，但 CoWoP 相关叙事要降温处理。** 高阶 HDI、SLP、800G/1.6T 光模块和先进封装确实需要更细线路；但“某一 NVIDIA 平台必然大规模采用 mSAP”目前缺少官方 BOM。mSAP 改善布线密度和线形控制，不会自动解决低损耗材料、散热、微孔可靠性等其他问题。
- **股票已经明显交易技术升级预期。** 芯碁微装、臻鼎等相关标的在 2026 年曾大幅上涨，随后出现月度回撤；三孚新科等概念映射公司波动更大。后续应优先验证重复订单、量产稼动率、良率和 mSAP 专项收入，而不是继续扩大概念名单。

## 一、mSAP 到底是什么

> **本节结论：** mSAP 的核心不是“少刻一点铜”，而是先用光阻定义线路位置，再通过电镀把目标线路长到所需厚度，最后只蚀刻很薄的底铜。

### 1. 先理解线宽/线距

PCB 上两条铜线路的宽度和间距通常写成 **L/S（Line/Space）**。

- `50/50 μm` → 线路宽约 50 μm，相邻线路间隔约 50 μm。
- `20/20 μm` → 在相同面积内可以放入更多线路，但对曝光、镀铜和缺陷控制要求显著提高。
- 数字更小不必然代表整板更好 → 电流承载、阻抗、材料损耗、散热和可靠性仍需共同设计。

不同厂商公布的能力值可能分别指样品、局部层、量产最小值或设计规则，不能直接混排为统一排名。例如京瓷公开的是 `40/40 μm 以下`和图形精度，山下材料公开的是 FPC `30/30 μm`，崇达技术披露的是 `20/20 μm` 产品量产。它们的板材、层数、尺寸和验证条件并不相同。[京瓷 mSAP 基板](https://www.kyocera.co.jp/prdct/board/search_application/detail/msap_outline.html) · [山下材料 mSAP FPC](https://www.yamashita-net.co.jp/fpc_m-sap/) · [崇达技术投资者交流](https://static.cninfo.com.cn/finalpage/2025-09-18/1224667439.PDF)

### 2. 三种线路形成方法

**减成法（Subtractive）**

- 起点 → 基材表面已有较厚铜层。
- 做法 → 用光阻保护需要的线路，再蚀刻掉其余铜。
- 优点 → 工艺成熟、成本低、适合大量普通 PCB。
- 限制 → 蚀刻会同时向下和向侧面进行；铜越厚、线路越细，侧蚀越难控制。

**改良型半加成法（mSAP）**

- 起点 → 带有约 1.5～5 μm 极薄底铜的 CCL/RCC，或先把面铜减薄。
- 做法 → 贴干膜、曝光显影，在开口位置电镀铜形成线路，去膜后通过闪蚀去掉裸露底铜。
- 优点 → 只需蚀刻极薄底铜，线路侧壁更垂直，线宽误差和阻抗波动更容易控制。
- 定位 → 传统 HDI 与 IC 载板之间的桥梁，常用于高阶 HDI、类载板（SLP）、精细 FPC 和部分封装基板。

**半加成法（SAP）**

- 起点 → 绝缘树脂表面，不依赖原有铜箔作为底层。
- 做法 → 粗化/活化绝缘层，形成极薄化学铜种子层，再曝光、电镀和去除种子层。
- 优点 → 可以进一步缩小线路，常用于高端 IC 封装基板。
- 难点 → 绝缘层与铜的附着、微孔金属化和表面处理窗口更严格，改造成本更高。

上述区间只代表常见产业分工，不是强制标准。PCB Technologies 的技术说明把 mSAP 描述为传统 HDI 厂向更高解析度升级的较低改造成本方案，并把 SAP 放在约 5 μm 级能力；具体量产边界仍由材料、设备和良率共同决定。[PCB Technologies 访谈](https://www.pcb-technologies.com/article/what-msap-technology-can-do-for-your-advanced-applications/)

### 3. mSAP 的简化流程

1. **准备极薄底铜** → 使用载体极薄铜箔，或把普通面铜均匀减薄。
2. **钻孔与除胶渣** → 通过激光/机械钻形成微孔，并清除孔壁树脂残留。
3. **沉铜/闪镀** → 使微孔和板面具备连续导电层。
4. **贴合高解析干膜** → 光阻必须均匀贴合极薄铜表面。
5. **激光直接成像（LDI）** → 把数字线路图形精确曝光到干膜上。
6. **显影** → 打开需要电镀成长铜线路的位置。
7. **图形电镀与填孔** → 增厚线路，同时控制微孔填充和全板铜厚均匀性。
8. **退膜** → 去除剩余光阻，露出不需要的极薄底铜。
9. **闪蚀** → 快速蚀刻裸露底铜，同时尽量不损伤已经形成的线路。
10. **AOI 与电测** → 检查开路、短路、残铜、缺口、线宽和对位误差。

[AT&S 的官方说明](https://ats.net/en/technologies/msap/)和[关西电子工业的流程介绍](https://www.kansaidenshi.com/product/msap/)均强调：mSAP 不再从整层厚铜中刻出线路，而是只在目标区域增加铜。

### 4. mSAP、SLP、HDI 和 ABF 不是同义词

**HDI（高密度互连板）**

- 定义 → 使用微孔、细线路和高密度层间互连的 PCB 类别。
- 与 mSAP 关系 → 高阶 HDI 可以采用 mSAP，也可以采用其他精细线路工艺。

**SLP（类载板）**

- 定义 → 线路尺度接近封装载板、但仍属于 PCB 体系的高密度主板。
- 与 mSAP 关系 → mSAP 是 SLP 的主流实现方式之一，SLP 不是 mSAP 工艺本身。

**ABF 封装基板**

- 定义 → 使用 Ajinomoto Build-up Film 等绝缘膜构建多层精细线路的 IC 封装基板。
- 与 mSAP 关系 → 高端 ABF 基板更多采用 SAP；部分核心层、不同产品或过渡工艺可能使用 mSAP，不能把 ABF 市场全部算成 mSAP 市场。

**ETS（嵌入式线路基板）**

- 定义 → 把铜线路部分嵌入介质，进一步改善线形和微细化能力。
- 与 mSAP 关系 → 是另一种载板结构/工艺路线，可与 mSAP/SAP 能力并行存在。

## 二、为什么传统工艺会遇到极限

> **本节结论：** 手机主板证明了 mSAP 的大规模制造价值；AI 时代新增的是更大尺寸、更高层数、更高频率和更多互连同时出现，而不是把手机 SLP 工艺原样搬到服务器。

### 1. 手机是最早的大规模练兵场

智能手机希望在更小主板面积内放入处理器、存储、射频、电源和连接器。传统减成法的线宽/间距受到侧蚀限制，mSAP 则能在熟悉的 HDI 材料体系上实现更细线路。因此，消费电子 SLP 成为早期量产场景。

Qnity Electronics 的技术文章指出，mSAP 从薄铜 CCL 出发，比完全改变到 SAP 更贴近传统 HDI 厂的工艺经验；文中以 3 μm 底铜和约 30/30 μm 的手机 SLP 为例。[Qnity Electronics 技术说明](https://www.qnityelectronics.com/blogs/smartphone-functionality-new-metallization-processes.html)

这段历史说明 mSAP 已不是实验室概念，但手机成功不代表服务器板可以直接复制：服务器 PCB 面积更大、层数更多，尺寸涨缩、镀铜均匀性和长期可靠性约束不同。

### 2. AI 服务器与交换机为什么可能扩大应用

- **芯片 I/O 增加** → GPU、ASIC、CPU、HBM 和网卡周围需要更多连接，板级逃逸布线密度提高。
- **高阶 HDI 导入** → 服务器主板从普通高多层板向 HLC+HDI 演进，微孔和精细线路数量增加。
- **800G/1.6T 光模块** → 小尺寸板上承载更多高速通道，线宽一致性和阻抗控制更重要。
- **交换机容量提高** → 芯片周围布线、连接器和光电接口密度继续上升。
- **先进封装外溢** → 封装尺寸扩大、层数增加，推动 SAP 载板扩产，同时让部分 PCB/类载板工艺向 mSAP 靠拢。

臻鼎 2025 年公开材料把高端 IC 载板、高端 HDI/mSAP 和 HLC 厚大板的工艺整合列为下一代产品共同能力，并披露其已经具备 mSAP、HDI 和 HLC 量产能力。[臻鼎 2025 年业绩资料](https://www.zdtco.com/upload/2025_08_122/20250812133306ej3q4p6Zd1.pdf)

### 3. CoWoP 叙事需要单独验证

市场把 CoWoP 描述为让芯片/中介层更直接连接到高密度 PCB，从而提高 PCB 的精细线路要求。这个方向若实现，确实可能扩大 mSAP、SAP 或其他类载板工艺的应用。

但截至本报告日期：

- 未找到 NVIDIA 官方量产 BOM 确认 CoWoP 的具体 mSAP 工艺、供应商和单板价值量；
- 多数公开信息来自券商、产业媒体和投资者交流转述；
- 胜宏科技港股文件使用的是“研究先进工艺、争取建立优势”等前瞻性表述，不等于已经形成 CoWoP/mSAP 量产收入。[胜宏科技港股文件](https://www1.hkexnews.hk/app/sehk/2025/107904/documents/sehk25112802785.pdf)

因此，CoWoP 应放在“高弹性待验证变量”，不能作为当前 mSAP 收入的既成事实。

### 4. mSAP 不会自动解决所有高速问题

mSAP 主要改善布线密度、线路截面和几何一致性。高速信号性能还依赖：

- 低 Dk/Df 的玻纤布和树脂；
- 低粗糙度铜箔，减少导体损耗；
- 微孔堆叠和孔铜疲劳可靠性；
- PCB 层叠、走线、连接器和过孔设计；
- 板面翘曲、尺寸涨缩和层间对位；
- 散热路径与电源完整性。

所以“采用 mSAP”不能等价为“高速低损耗板”，也不能仅凭 L/S 数字判断服务器 PCB 质量。

## 三、量产壁垒集中在哪里

> **本节结论：** mSAP 的护城河是窄窗口工艺的协同控制。任一环节的小波动都可能在大尺寸、多层板上放大成良率损失。

### 1. 载体极薄铜箔

普通 1.5～5 μm 铜箔太软、容易起皱或破损，通常贴在较厚载体铜箔上完成运输和层压，再把载体剥离。

关键指标包括：

- 极薄铜厚度与全幅均匀性；
- 载体剥离力稳定性；
- 表面粗糙度与树脂附着平衡；
- 高温压合后能否稳定剥离；
- 大卷宽幅和批次一致性。

三井金属公开称 MicroThin 为 1.5～5 μm 载体极薄铜箔，并称其载体极薄铜箔全球份额超过 95%，主要用于半导体封装基板和智能手机主板精细线路。[三井金属产品页](https://em.mitsui-kinzoku.com/douhaku/technology/microthin) 该数据来自公司自身，应视为厂商口径，但足以说明该环节高度集中。

### 2. 高解析耐电镀干膜

干膜既要解析极细线条，又要在电镀液和喷流环境中保持附着，不能发生膜边翘起、底部残胶或显影不足。

关键指标包括：

- 分辨率和线形矩形度；
- 对极薄铜表面的附着；
- 耐酸铜电镀和耐显影性能；
- 曝光灵敏度、批次稳定性；
- 退膜后是否残留。

旭化成 SUNFORT ADP/DA 系列明确面向 LDI 与 mSAP/SAP 电镀，强调高解析、附着和耐化学性。[旭化成干膜产品页](https://www.asahi-kasei.co.jp/sunfort/en/products/adp_da.html)

### 3. 激光直接成像与对位

传统曝光使用实体光罩；LDI 直接读取数字图形曝光，能够补偿板材涨缩并提高多层对位精度。

关键指标包括：

- 最小解析度，不只是实验室最小线宽；
- 大板面全幅对位和畸变补偿；
- 曝光效率与单位面积产能；
- 光源稳定性、自动聚焦和设备稼动率；
- 与不同干膜、阻焊材料的工艺窗口。

SCREEN 公开的 PCB 全流程方案把 LUPIOS/Ledia 直接成像系统用于 SAP/mSAP 精细图形，并强调 mSAP 中光阻附着、均匀性和定位精度。[SCREEN PCB 解决方案](https://www.screen.co.jp/pe/en/innovation-studio/solution/total-solution.html)

### 4. 图形电镀与微孔填孔

电镀需要同时让线路长到目标厚度、填满微孔，并保持大板不同区域的铜厚一致。

关键指标包括：

- 全板铜厚均匀性；
- 高纵横比微孔的填孔率；
- Dimple（填孔凹陷）和过镀凸起；
- 铜晶粒、延展性和界面结合；
- 药水寿命、颗粒污染与在线分析；
- 电流密度、产能和水/化学品消耗。

MKS 旗下 Atotech 的 Uniplate IP3 明确面向下一代 HDI/mSAP 闪镀，重点是极薄芯板的铜厚均匀性、流场、电场和颗粒管理。[Atotech Uniplate IP3](https://www.atotech.com/products/electronics/electronics-equipment/uniplate-ip3/)

### 5. 闪蚀窗口

闪蚀需要完全去掉线路间的极薄底铜，又不能过度缩窄已经电镀形成的线路。底铜稍厚、厚度不均或蚀刻速度漂移，都可能导致残铜短路或线路变窄。

关键指标包括：

- 蚀刻速率和选择性；
- 不同方向/位置的均匀性；
- 线路底部 Undercut；
- 残铜、粗糙度和阻抗偏差；
- 药水在线控制和废液处理。

### 6. 检测和反馈闭环

精细线路缺陷可能只有数微米，普通目检无法覆盖。量产必须把 AOI、线宽测量、电测和缺陷分类反馈到曝光、电镀和蚀刻参数。

这也是为什么 KLA/Orbotech、SCREEN 等检测和软件供应商仍然重要：mSAP 不是单设备制程，而是数据反馈驱动的整线工程。

## 四、产业链与利润位置

> **本节结论：** 最稀缺的通常不是通用 PCB 产能，而是具有高份额的极薄铜箔、能覆盖关键工序的设备/化学品平台，以及已经跑通客户认证和良率的量产线。

### 上游材料

**载体极薄铜箔**

- 龙头代表 → 三井金属 MicroThin。
- 直接作用 → 为 mSAP 提供可搬运、可层压、可剥离的极薄底铜。
- 护城河 → 薄箔制造、载体剥离层、表面处理、宽幅均匀性和客户认证。
- 主要客户 → 封装基板和高阶 HDI/SLP 厂；具体客户名单通常未披露。
- 价值判断 → 当前公开证据最明确、集中度最高的上游环节之一。

**高解析干膜**

- 主要代表 → 旭化成 SUNFORT、Qnity/DuPont 体系等。
- 直接作用 → 把 LDI 图形转成可耐受电镀的精细光阻开口。
- 护城河 → 感光材料配方、解析度、附着、耐镀和客户工艺协同。
- 中国国产化 → 湖南初源等厂商推进 LDI/SAP/mSAP 干膜，但公开资料多处于验证和国产替代阶段。

**电镀、闪蚀与表面处理化学品**

- 全球代表 → MKS/Atotech、MacDermid Alpha、Qnity Electronics。
- 中国代表 → 三孚新科、天承科技等 PCB 专用化学品厂商。
- 直接作用 → 沉铜、图形电镀、填孔、退膜、闪蚀和表面处理。
- 护城河 → 药水配方只是起点，还需要在线分析、设备协同和驻厂服务。
- 关键提醒 → 公司拥有某款 mSAP 药水，不等于已获得整线大规模收入。

### 中游设备

**LDI 与直写光刻**

- 全球代表 → SCREEN、KLA/Orbotech。
- 中国代表 → 芯碁微装。
- 直接作用 → 高解析图形曝光、层间对位和板材涨缩补偿。
- 护城河 → 光学引擎、算法、精度、吞吐量、设备稳定性和材料适配。

**钻孔与成型设备**

- 全球/中国代表 → 大族数控在 PCB 钻孔、成型和检测设备具备广泛客户覆盖。
- 直接作用 → 微孔、盲孔、外形和多层对位，是 mSAP 线路互连的前置条件。
- 护城河 → 高精度运动控制、激光工艺、钻孔效率和整线服务。
- 关键提醒 → 大族数控 2025 年报中的“mSAP 3.0”是公司研发描述，并非通用行业标准。

**电镀与湿制程设备**

- 全球代表 → MKS/Atotech；MacDermid Alpha 主要提供配套工艺化学品。
- 中国代表 → 东威科技等 PCB 电镀设备厂商。
- 直接作用 → 沉铜、闪镀、图形镀铜、填孔和药水循环。
- 护城河 → 流场/电场、均匀性、颗粒控制、自动化和化学品协同。

**AOI 与数据软件**

- 全球代表 → KLA/Orbotech、SCREEN。
- 直接作用 → 发现微米级残铜、缺口、短路、开路和对位缺陷。
- 护城河 → 光学、算法、缺陷数据库和生产数据闭环。

### 下游制造

**高阶 HDI/SLP 厂**

- 主要代表 → 臻鼎、AT&S、鹏鼎控股、华通、欣兴、健鼎等。
- 商业价值 → 更高线路密度和产品单价，但承担较高设备折旧和良率爬坡。
- 客户 → 手机、可穿戴、汽车、AI 服务器、交换机、光模块厂商。

**封装基板厂**

- 主要代表 → 欣兴、揖斐电、神钢电机、景硕、三星电机、深南电路、兴森科技等。
- 工艺关系 → 高端产品多使用 SAP；部分产品、核心层或过渡路线可能使用 mSAP。
- 关键提醒 → 不能把整个 ABF/BT 封装基板收入算作 mSAP 收入。

### 谁更容易获得利润

1. **份额高度集中的专用材料** → 例如载体极薄铜箔，认证和切换成本高。
2. **横跨多客户的关键设备/化学品平台** → 下游扩产时先获得订单，但具有明显资本开支周期。
3. **已经完成量产认证的 PCB 厂** → 可获得高阶产品溢价，但盈利取决于良率、稼动率和客户议价。
4. **只有研发概念、尚无量产的厂商** → 股价弹性可能很高，经营兑现最弱。

## 五、全球公司格局

> **本节结论：** mSAP 不是由单一国家垄断的产业。日本强在极薄铜箔、干膜与设备；台湾强在高阶 PCB 规模量产；欧洲有 AT&S 这样的高端板厂；美国强在电镀化学品、检测和终端需求；中国正在设备、化学品和板厂三个环节同时国产化。

### 中国台湾：高阶 PCB 规模量产中心

#### 臻鼎科技 · Zhen Ding · `TWSE 4958`

- 行业位置 → 公司披露 2025 年连续第 9 年为全球最大 PCB 制造商。
- mSAP 证据 → 官方业绩材料明确写有经过验证的 mSAP、HDI、HLC 量产能力。
- 主要产品 → 移动通信 PCB、服务器/光通信 PCB、汽车电子和 IC 载板。
- 2025 年经营 → 营收 1,825.2 亿新台币，同比增长 6.3%；服务器/光学与 IC 载板收入创新高，AI 相关应用接近总收入 70%。[臻鼎 2025 年业绩](https://www.zdtco.com/en/news/Financials/ZhenDingReportedItsOperatingResultsfortheFullYearof2025)
- 主要客户 → 公司未在相关材料中逐项披露 mSAP 客户与收入，不能把全部 AI 收入视为 mSAP。
- 排名依据 → PCB 总收入规模、连续全球第一的公司披露、mSAP 量产能力；不是 mSAP 专项市场份额。

#### 欣兴电子 · Unimicron · `TWSE 3037`

- 行业位置 → 全球封装基板和高阶 PCB 主要厂商。
- 主要产品 → ABF/BT 载板、HDI 和多层 PCB。
- 工艺关系 → 封装基板核心能力更偏 SAP，HDI/类载板涉及精细线路；公开材料没有充分拆出 mSAP 专项收入。
- 排名依据 → 封装基板产业地位和高阶制造能力，不强行称其为 mSAP 第二名。

#### 其他代表

- 华通、健鼎、景硕、台燿供应链 → 分别覆盖高阶 PCB、载板或关键材料。
- 研究重点 → 哪些产线采用 mSAP、对应产品和客户，而不是公司是否处于台湾 PCB 集群。

### 日本：关键材料与设备最强

#### 三井金属 · `TSE 5706`

- 行业位置 → 载体极薄铜箔技术与份额标杆。
- 主要产品 → 1.5～5 μm MicroThin 载体极薄铜箔。
- mSAP 关系 → 作为底铜用于超高精度 PCB；公司称该产品是行业全球标准并拥有超过 95% 份额。
- 新进展 → 2026 年完成可耐 350°C 以上工艺的高温 MicroThin 技术，扩大到 MPI、LCP、PTFE 等高温基材。[三井金属 2026 年公告](https://www.mitsui-kinzoku.com/en/news_a/?TabModule1277=0&dispmid=1140&itemid=1806)
- 护城河 → 薄铜、载体剥离、表面粗化和量产一致性。
- 主要客户 → 未逐项披露。

#### SCREEN Holdings · `TSE 7735`

- 行业位置 → PCB 直接成像、涂布、显影蚀刻和检测方案代表。
- mSAP 关系 → 官方全流程明确覆盖 SAP/mSAP 图形和阻焊工艺。
- 护城河 → 光学曝光、对位、湿制程与检测组合。
- 排名依据 → 官方产品覆盖和工艺完整性；无可靠数据支持强行排全球第二。

#### 旭化成 · `TSE 3407`

- 行业位置 → 高解析干膜重要供应商。
- 主要产品 → SUNFORT LDI 干膜。
- mSAP 关系 → ADP/DA 系列明确强调 mSAP/SAP 电镀耐受、解析和附着。
- 护城河 → 光刻材料配方、客户工艺协同和批次稳定性。

#### 京瓷 · `TSE 6971`

- 行业位置 → mSAP 基板应用代表，而非全球规模第一的 mSAP 板厂。
- 公开能力 → `L/S 40/40 μm 以下`、图形精度 `±10 μm 以下`，应用于车载 ADAS、ECU、通信和 HPC。
- 产业意义 → 说明 mSAP 不只用于手机，也能用于高频、汽车和计算场景。

#### 揖斐电 · Ibiden · `TSE 4062`

- 行业位置 → AI GPU/CPU 高端 IC 封装基板龙头之一。
- 工艺关系 → 官方 2025 综合报告强调 AI 基板变大、层数增加，使 SAP 产能负荷上升，而非把其核心路线称作 mSAP。[揖斐电 2025 综合报告](https://www.ibiden.com/ir/items/IntegratedReport2025_en.pdf)
- 研究意义 → 它是区分 SAP 与 mSAP 的重要案例：都受益于高密度互连，但不是同一投资口径。

### 欧洲：AT&S 是清晰的 mSAP 板厂标杆

#### AT&S · `VIE ATS`

- 行业位置 → 欧洲高端 PCB 与 IC 载板主要厂商。
- mSAP 证据 → 上海工厂制造 HDI/mSAP PCB；重庆二厂生产移动应用高端 mSAP PCB；公司另有 IC 载板业务。
- 主要应用 → 移动设备、汽车/工业、智能基础设施、光传输和 IC 载板。
- 护城河 → 高端 PCB 与载板工艺、全球工厂、客户联合开发。
- 主要风险 → 新厂折旧、客户集中、稼动率和资本结构。
- 原始来源 → [AT&S 2024/25 年报](https://ats.net/en/download/annual-report-2024-25/?refresh=698d420bbd7a71770865163&wpdmdl=44685) · [mSAP 技术页](https://ats.net/en/technologies/msap/)

#### Optiprint · 非上市

- 行业位置 → 瑞士高端 PCB/mSAP 技术代表。
- 公开能力 → 面向 `<25 μm` 精细线路、高频、医疗和传感器。
- 产业意义 → 欧洲存在高端小批量和专用场景能力，但规模与亚洲消费电子大厂不同。
- 原始来源 → [Optiprint mSAP](https://www.optiprint.ch/en/products/msap/index.php)

### 美国：设备、化学品与终端需求

#### MKS Instruments / Atotech · `NASDAQ MKSI`

- 行业位置 → PCB/载板电镀化学品和设备平台。
- 主要产品 → 除胶渣、金属化、沉铜、图形电镀、填孔、闪镀和表面处理。
- mSAP 关系 → 官方产品明确覆盖 HDI、mSAP、amSAP 和封装基板。
- 护城河 → 化学品、设备、软件和现场服务一体化，认证粘性高。
- 主要客户 → 官方以全球主要 PCB、HDI 和 IC 载板厂描述，具体名单未完整披露。

#### KLA / Orbotech · `NASDAQ KLAC`

- 行业位置 → PCB CAM、直接成像、AOI、检测与生产数据软件代表。
- mSAP 关系 → 精细线路需要更强检测与数据闭环；公司服务 PCB、IC 载板、MiniLED 和 5G 等制造。
- 护城河 → 光学检测、缺陷算法、CAM 软件和装机基础。
- 关键提醒 → KLA 业务范围很广，mSAP 对集团收入的纯度较低。

### 韩国

- 产业优势 → 三星电机等企业在高端封装基板和电子组件领域实力强。
- 工艺口径 → 高端封装基板更多公开为 SAP/ABF 路线；目前没有足够公开证据对韩国 mSAP PCB 厂做可靠第一、第二排名。
- 研究方式 → 按具体 HDI/SLP 产品和产线验证，不能把全部韩国封装基板产能纳入 mSAP。

## 六、中国公司进度分层

> **本节结论：** 中国 mSAP 产业链已经从“设备和药水研发”进入部分客户量产，但公司间证据强度差异极大。量产线、重复订单和专项收入是下一步分水岭。

### A 级：披露明确量产或客户重复订单

#### 崇达技术 · `SZSE 002815`

- mSAP 主体 → 控股子公司普诺威，聚焦 BT 等封装基板。
- 公开进度 → mSAP 产线 2023 年 9 月连线投产；`20/20 μm` 产品已量产，相关产品已大批量出货；ETS 能力达到 `15/15 μm`。
- 主要应用 → RF 射频、SiP、PMIC、TPMS 等封装基板。
- 证据强度 → 高；公司投资者交流直接披露产线、能力和出货状态。
- 核心风险 → 上市公司整体业务包含普通 PCB、FPC 等，mSAP 专项收入和利润未单列。
- 原始来源 → [崇达技术 2025 年投资者交流](https://static.cninfo.com.cn/finalpage/2025-09-18/1224667439.PDF)

#### 芯碁微装 · `SSE 688630`

- mSAP 环节 → LDI/直写光刻设备，不生产 PCB。
- 公开进度 → ICS 封装载板 LDI 设备 MAS 6P 在头部客户完成验收并投入量产，获得批量订单；公司披露设备解析能力达到 `6/6 μm`。
- 主要客户 → 鹏鼎控股、沪电股份、深南电路、胜宏科技、景旺电子等 PCB 厂商；这表示客户覆盖，不代表每家都用同一 mSAP 机型。
- 证据强度 → 高；验收、量产和批量订单均有半年报披露。
- 核心风险 → 设备销售受下游资本开支影响；单机分辨率不等同于客户整线量产 L/S。
- 原始来源 → [芯碁微装 2025 年半年报](https://static.cninfo.com.cn/finalpage/2025-08-28/1224592479.PDF)

### B 级：具备工艺或形成产品，但专项经营数据不足

#### 兴森科技 · `SZSE 002436`

- mSAP 环节 → PCB、HDI、SLP、测试板与封装基板制造。
- 公开进度 → 公司披露持续精进 Tenting、mSAP 和 SAP 工艺，产品覆盖高多层 PCB、HDI、SLP、ATE 测试板和封装基板。
- 证据强度 → 中；工艺能力和产品覆盖明确，但 mSAP 专项产能、客户、销量和利润没有拆分。
- 核心风险 → 广州/珠海/英国等不同业务和封装基板爬坡影响整体利润，不能按纯 mSAP 公司估值。
- 原始来源 → [兴森科技 2025 年年报](https://pdf.dfcfw.com/pdf/H2_AN202604241821559474_1.pdf)

#### 臻鼎集团大陆主体 / 鹏鼎控股 · `SZSE 002938`

- mSAP 环节 → 高阶 HDI、SLP 和移动通信 PCB。
- 公开进度 → 集团层面拥有经过验证的 mSAP 量产能力；上市主体与集团业务边界需要按年报核对。
- 证据强度 → 中高；集团能力清楚，但不能把臻鼎集团全部 mSAP 收入直接归到鹏鼎控股。
- 核心风险 → 客户集中、消费电子周期和不同法律主体口径混用。

#### 三孚新科 · `SSE 688359`

- mSAP 环节 → 专用化学品与电镀工艺方案。
- 公开进度 → 公司称 mSAP 制程化学品完成阶段性测试，部分产品已在头部 PCB 客户端上线应用。
- 证据强度 → 中；已有客户端应用，但“部分药水上线”与覆盖整条 mSAP 化学品链不同。
- 核心风险 → 公司整体仍处于亏损状态，mSAP 专项收入、毛利和客户集中度未清晰披露。
- 原始来源 → [三孚新科 mSAP 专题](https://www.gzsanfu.com.cn/displaynews-233-1.html) · [2025 年半年报](https://dataclouds.cninfo.com.cn/shgonggao/2025/2025-08-26/bdb4462b818b11f0a10afa163e957f7a.pdf)

### C 级：研发、储备或前瞻布局

#### 大族数控 · `SZSE 301200` / `HKEX 03200`

- mSAP 环节 → 钻孔、激光加工、成型、检测和整线方案。
- 公开进度 → 2025 年报提出继续投入 mSAP 工艺方案，并储备公司所称“mSAP 3.0”，面向下一代 SLP/RCC 更小特征加工。
- 证据强度 → 中；PCB 设备收入和客户覆盖强，但 mSAP 3.0 仍属于研发/方案储备表述。
- 主要客户 → 公司披露覆盖大量全球 PCB 百强，包括胜宏、臻鼎、欣兴、AT&S、深南、沪电等；不能据此推断 mSAP 专项设备份额。
- 原始来源 → [大族数控 2025 年报](https://www.hkexnews.hk/listedco/listconews/sehk/2026/0416/2026041601647_c.pdf)

#### 胜宏科技 · `SZSE 300476` / 港股上市主体

- mSAP 环节 → AI 服务器高多层 PCB、高阶 HDI 与潜在 CoWoP/类载板。
- 公开进度 → 公司港股文件把 mSAP 列为持续研发的先进工艺，用于建设高性能数据中心 PCB 的跨周期能力。
- 证据强度 → 中低；高端 AI PCB 已有经营验证，但 mSAP/CoWoP 专项量产数据不足。
- 核心风险 → 市场容易把高层数 PCB 收入全部解释成 mSAP，实际两者不是同义词。

### 证据分级规则

- **A级** → 公司明确披露量产线、量产规格、批量出货或设备重复订单。
- **B级** → 公司明确披露工艺能力、产品或客户端应用，但缺专项销量/收入。
- **C级** → 研发、储备、客户验证、展会样品或前瞻项目。
- **D级** → 券商、媒体或社交账号转述，找不到公司/客户原始文件。

对 mSAP 这类工艺板块，最有价值的进展是 `C → B → A`，而不是同一级别内出现更多公司名字。

## 七、公开人物与社交平台观点

> **本节结论：** mSAP 是工程工艺，社交平台上最常见的问题是把路线图当成量产订单。官方业绩说明和技术负责人访谈的验证价值更高。

### 臻鼎董事长沈庆芳 · 官方业绩资料

- 身份 → 臻鼎科技董事长。

## 九、未来驱动、风险与跟踪清单

> **本节结论：** mSAP 的长期方向是确定的微细化，短期业绩却取决于客户平台切换和量产良率。最大的研究错误是把技术必要性直接等同于所有相关公司的利润增长。

### 未来 3～5 年驱动

1. **服务器高阶 HDI 化** → 更多微孔和芯片逃逸布线，提高精细线路需求。
2. **800G/1.6T 光通信** → 光模块和交换机板向更小、更密和更严格阻抗控制升级。
3. **SLP 从手机扩展到汽车、HPC 和专用模组** → mSAP 的应用边界扩大。
4. **中国设备与化学品国产化** → 下游扩产为 LDI、电镀和药水厂提供验证机会。
5. **先进封装与 PCB 边界模糊** → SAP、mSAP、ETS、RDL 和玻璃基板路线之间形成新的工艺组合。
6. **低损耗材料与精细线路协同** → 高温可剥载体铜箔、RCC、MPI/LCP/PTFE 等新材料推动 mSAP 适配升级。

### 核心风险

**把全行业规模当成 mSAP 市场规模**

- 风险 → 用全球 PCB、HDI 或 ABF 总产值推算 mSAP 收入，显著高估可寻址市场。
- 验证 → 要求厂商披露 mSAP 产线、面积、产品和收入，而不是使用大行业分母。

**路线替代**

- 风险 → 当线路继续缩小，SAP、ETS、amSAP、RDL 或玻璃基板可能替代部分 mSAP。
- 验证 → 观察客户设计规则、材料起点和目标 L/S，而不是争论哪个缩写更先进。

**良率爬坡慢于资本开支**

- 风险 → 新线设备到位但无法稳定量产，折旧先发生、收入后兑现。
- 验证 → 设备验收、月度产出、良率、稼动率和单位制造成本。

**客户平台推迟**

- 风险 → AI/手机平台改版、需求不及预期或认证延迟，使 mSAP 产线闲置。
- 验证 → 重复订单、多个客户平台和产品生命周期。

**上游单一来源**

- 风险 → 高份额极薄铜箔、干膜或设备出现供应中断，影响整线。
- 验证 → 第二供应商认证、库存、区域产能和客户双供进度。

**国产替代不等于利润替代**

- 风险 → 国产设备/药水以低价进入，技术合格但售后成本高、毛利不佳。
- 验证 → 毛利率、服务费用、应收账款、质保支出和重复订单。

**主题交易拥挤**

- 风险 → 股价提前反映尚未发生的 CoWoP、mSAP 3.0 或大客户订单。
- 验证 → 把市值增量与可验证的新增利润逐项对照。

- [ ] 设备国产化后的良率、稼动率和总拥有成本是否真正达到进口方案水平？

## 结论

mSAP 是 PCB 微细化中非常重要、但容易被概念化的一项工艺。它的产业价值不在一个单独产品，而在于把极薄铜箔、干膜曝光、图形电镀、闪蚀和检测连成稳定的量产系统。

从竞争格局看，三井金属在载体极薄铜箔上最具明确稀缺性；臻鼎和 AT&S 是公开证据较清楚的规模 mSAP 板厂；MKS/Atotech、SCREEN、KLA 等掌握关键设备与化学品平台。中国公司中，崇达技术的量产出货证据和芯碁微装的设备验收/批量订单证据较强；兴森科技、三孚新科、大族数控和胜宏科技分别处于工艺覆盖、客户端应用或研发推进阶段，不能使用同一成熟度评价。

研究这个板块最有效的方法，是每季度检查三件事：**是否有真实量产客户、良率和稼动率是否稳定、mSAP 是否形成可辨认的收入和利润。** 如果只有更小的实验室 L/S 或更宏大的 AI 路线图，证据仍不够。
